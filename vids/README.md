# Device demo media

Recorded from an RG477M. These files illustrate the launcher UI; no completed gameplay or
performance result is asserted.

- [Animated gallery preview](gallery-preview.gif): a short excerpt from the current device
  capture, 480×360, 6 fps, played at 2× speed, with no audio. The source recording is not
  included in the repository.
- [Full demo MP4](retro-launcher-demo.mp4): approximately 39 seconds, 1280×960, 30 fps,
  H.264, no audio, approximately 12.4 MB. Includes gallery browsing, one launch handoff,
  and a final gallery view. Web playback uses fast-start MP4 metadata.
- [Gallery screenshot montage](gallery-screenshots.jpg): six stills from the demo.
