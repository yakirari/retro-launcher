# Device demo media

Recorded from an RG477M on 2026-10-11. These files illustrate the launcher UI and a handoff
to a separately installed game hub. No completed gameplay or performance result is asserted.

- [Full demo MP4](retro-launcher-demo.mp4): approximately 39 seconds, 1280×960, 30 fps,
  H.264, no audio, approximately 12.4 MB. Includes gallery browsing, one launch handoff,
  and a final gallery view. Web playback uses fast-start MP4 metadata.
- [Animated gallery preview](gallery-preview.gif): a shortened gallery-only excerpt,
  480×360, 6 fps, played at 2× speed to keep the README download small.
- [Gallery screenshot montage](gallery-screenshots.jpg): six stills from the demo.
