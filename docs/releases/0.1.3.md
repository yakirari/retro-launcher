# Retro Launcher 0.1.3 — Experimental preview

Fixes a device-confirmed gallery crash and improves Shelf presentation and emulator selection.
Requires Android 13 or newer; emulators and games are installed separately.

## Download and installation

Download **retro-launcher-0.1.3-preview-debug.apk** and **SHA256SUMS** from the release Assets.
Verify the checksum before installing.

**APK SHA-256:** `b3eaf2ec5d3e49f4d51b140a1abb41e7a3ff89e8ba13b8738b3549a490ef3e9c`

**Debug-signed testing build, not production-signed.** Package `com.ariy.retrolauncher`, version
`0.1.3`, version code `4`. Uses the same local debug key as the previous previews.
Install over a same-key preview to retain data. If Android reports a signing conflict, stop:
uninstalling or clearing storage loses the library and grants. Keep another Home launcher installed.

## Changes

- **Gallery crash:** retained device traces showed `IllegalArgumentException: fromIndex: 3 > toIndex: 1`
  during artwork prefetch. Switching from a long gallery to a shorter list could leave a stale lazy
  scroll index. Focus is now clamped to the current list; prefetch ranges are bounded and tested
  for empty, short, shrinking and extreme-index inputs.
- **Shelf layout:** smaller normalized artwork inside fixed, separated slots with a shared baseline.
  Selection no longer changes size, vertical offset or spacing. Transparent template margins are
  cropped only for display; source artwork remains unchanged.
- **Shelf selection/title:** selected title is centered below the tile, without a title frame.
  The rectangular selection frame is replaced by a soft shadow derived from the actual template
  or cabinet alpha silhouette. The platform badge remains bottom-left.
- **Emulator chooser:** scan alternatives show the installed app icon beside name/platform/core
  details. Icons load off the UI thread; unavailable icons use Android's fallback.
- Repository documentation explains installed emulator prerequisites, supported presets/cores,
  hub-created shortcuts and later rescans. The README includes a device gallery/launch demo.

## Validation and known limitations

- 206 JVM tests passed; app and Android instrumentation-test APKs compiled.
- Crash root cause verified against retained RG477M traces; regression tests exercise the invalid
  prefetch-range transition. This does not establish that every possible crash has been eliminated.
- APK signature/version verified. In-place RG477M installation/startup succeeded without clearing
  data; no AndroidRuntime crashes appeared in the inspected new-process log.
- Device UI/instrumentation execution, prolonged filter cycling, gameplay and shadow appearance
  are not claimed as verified. Prior captures showed Android Home settings rather than Shelf.
- This APK is debuggable; no production signing key is configured.
- Android lint remains blocked by the documented Compose/Kotlin metadata-reader incompatibility.
- No in-app backup/export exists. Reset launcher, uninstall and clearing storage lose data.
- Third-party artwork retains original source terms. Redistribution review for external cabinet
  references/derivatives remains unresolved; this preview does not grant blanket redistribution
  permission or relabel third-party assets as MIT. Licensing notices and artwork credits are attached.
