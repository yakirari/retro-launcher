# Retro Launcher 0.1.0 — First preview

The first experimental preview of Retro Launcher: a controller-friendly Android Home launcher
for retro and PC game libraries.

**Release status:** draft, prepared on 2026-10-11, with a debug-signed preview APK attached for testing.
Draft downloads require repository write access; they are not publicly available until the release
is published. Production signing and the third-party artwork redistribution review remain blockers
for public APK publication.

## Download and install the preview

1. Open this draft release while signed in with repository write access.
2. Under **Assets**, download **retro-launcher-0.1.0-preview-debug.apk** and **SHA256SUMS**.
3. Verify the APK's SHA-256 matches the checksum below and in SHA256SUMS.
4. Install the APK on Android 13+. If prompted, allow installation from your browser/file manager.
  This is the same debug-signed build verified and installed on the development RG477M.

**SHA-256:** `b64faf1ba303579440d8378a7075fb926d4230ba833c98c3ba8dbc2547ceca48`

**Testing build, not production-signed.** It can update an existing installation only when signed
with the same key. Builds from another machine and future production-signed builds may use a
different key. If Android reports a signature conflict, stop: uninstalling or clearing storage
would erase the launcher library and grants. Keep another Home launcher installed while testing.

## Requirements

- Android 13 or newer.
- Install emulators and game hubs separately. No emulator engines, games, ROMs, BIOS or firmware
  are included.
- Set Retro Launcher as the default Home app to approve and launch Android-published game shortcuts.
- Keep another Home launcher installed while testing this experimental version.

## Highlights

- Optional welcome setup scans a selected ROM root, recognizes supported platform folders, and
  imports games in cancellable batches without replacing existing library metadata.
- MAME onboarding offers installed standalone emulators and explicit named RetroArch core presets,
  including a confirmation when only one option is available. Install the selected core inside
  RetroArch and use a compatible ROM set; the launcher cannot inspect private core availability.
- Large manual and automatic imports prepare merges, deduplication and serialization off the UI
  thread, show progress, and retain completed batches if cancelled. Artwork is handled afterward.
- Compact onboarding, Options, Add and Edit dialogs give scrolling content more room on short
  landscape screens. Only essential headings/status/actions stay fixed where possible.
- **Player One Lounge**, formerly Basement 7, is the default wallpaper for an unset preference.
  Existing selections, including None and custom wallpapers, are retained. The other scenes are
  Neon Console Oasis, Mixtape Hideaway, Quarter Drop Arcade, Golden Era Game Room, Collector’s Vault,
  and After Hours Workshop.
- Global Grid and Shelf presets, independent tile counts, transparent tiles, controller navigation,
  and progressively loaded galleries.
- Separate Android Games and Emulators & Launchers galleries; Android-managed shortcuts for
  GameNative, GameHub, GameHub Lite and other publishers.
- ScummVM registered-game picker and exported configuration import; no guessed private targets.
- Optional artwork lookup, full-cover PS1 jewel-case template, editable launch targets/captions,
  and alphabetical, year and personal-popularity sorting.
- Explicit, Cancel-focused reset clears launcher-private data and grants, never shared ROMs or
  installed apps. There is no undo or in-app backup/export.

## Validation

- 190 JVM tests across 43 suites passed.
- Debug application and Android instrumentation-test APKs built successfully.
- Attached debug APK signature verified; package `com.ariy.retrolauncher`, version `0.1.0`, version code 1.
- The update installed over the existing application on an RG477M and launched successfully;
  the inspected process-specific AndroidRuntime log contained no crash entries.
- Device visual checks and instrumentation execution remain unverified: the captured screen was
  black and keyguard remained reported. Gameplay, frame-rate and large-library device benchmarks
  are not claimed.

## Known limitations and release blockers

- A production release signing key is not configured. The attached preview APK is debug-signed,
  not a production distribution artifact. Changing signing keys can prevent in-place updates;
  do not uninstall or clear storage merely to work around a signature mismatch.
- Redistribution rights for documented third-party cabinet downloads and derivatives still need
  review. Original launcher code/documentation and author-created artwork have their stated
  licensing scope; attribution does not grant blanket redistribution permission for external art.
- Android lint is blocked by the documented Compose/Kotlin metadata-reader incompatibility;
  no successful lint result is asserted.
- Emulator launch behavior depends on the installed version, its public contract, required cores,
  BIOS/settings and independent ROM access permissions. A scan is not a gameplay compatibility test.
- Hub private libraries and pins owned only by another Home launcher are not generally accessible.
- Artwork lookup needs network access, may find the wrong edition, and is optional for launching.
- Uninstalling, clearing storage or Reset launcher can lose library data; no in-app export is available.
