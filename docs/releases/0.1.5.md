# Retro Launcher 0.1.5 — Experimental preview

Artwork catalog and presentation improvements for Android 13 and newer. Emulators, ROMs and games
remain separate. Package `com.ariy.retrolauncher`, version `0.1.5`, version code `6`.

This is a **debug-signed testing build, not a production-signed release**.

## Changes

- Add shared arcade presentation fronts and indexed NES/SNES cartridge artwork catalogs.
- Preserve artwork provenance and source metadata, and report artwork-index loading failures rather
  than silently treating broken catalogs as empty.
- Improve adaptive gallery sizing, stacked presentation, console/cartridge matching and artwork
  memory handling.
- Consolidate packaged artwork and retain source/attribution notices with the app assets.
- Replace the README’s full-video link with a short, gallery-only animated preview; the two-minute
  source recording is not included in the repository.

## Validation and limitations

- The tagged GitHub Actions run builds the debug APK and runs JVM unit tests. Download its
  `retro-launcher-v0.1.5-debug-preview` artifact and verify it using `SHA256SUMS`.
- This APK uses the Android debug signing key and is not suitable for production distribution or
  upgrades from a differently signed installation.
- Full device UI stress testing, every emulator/game launch and gameplay compatibility are not
  certified. Follow the [user guide](../USER_GUIDE.md) and [third-party notices](../../THIRD_PARTY_NOTICES.md).
