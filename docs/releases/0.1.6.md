# Retro Launcher 0.1.6 — Experimental preview

Platform integration, curated artwork and more responsive library navigation for Android 13 and
newer. Emulators, ROMs, BIOS/firmware and games remain separate and are not included.

Package `com.ariy.retrolauncher`, version `0.1.6`, version code `7`. This is a **debug-signed
testing build, not a production-signed release**.

## Changes

- **Xbox:** Add Microsoft Xbox / X1 BOX platform support, including emulator discovery, ISO/XISO
  launch integration, ROM folder hints, Xbox-specific artwork lookup and platform badges.
- **ScummVM:** Add curated game-specific artwork, improve matching and cover fitting, and preserve
  dark artwork while making near-black backgrounds transparent.
- **Platform presentation:** Improve GameCube and arcade artwork sizing; refine platform-specific
  gallery layouts, emulator/app icon sizing and platform badges.
- **Search and navigation:** Add top-menu live search across game metadata, plus an internal keyboard
  that avoids dismissing results while typing and works better on compact screens.
- **Setup and launch:** Improve emulator discovery and shortcut handling, and add platform-specific
  launch cues.

## Validation and limitations

- The tagged GitHub Actions run builds the debug APK and runs JVM unit tests. Download the
  `retro-launcher-v0.1.6-debug-preview` artifact and attach the APK and `SHA256SUMS` to the draft
  release.
- The APK is debug-signed and is not suitable for production distribution or upgrades from a
  differently signed installation.
- Device installation and foreground-launch checks were completed for the development build.
  Full UI stress testing, every emulator/game launch and gameplay compatibility are not certified.
- The project maintainer confirmed redistribution rights for artwork bundled in this release; see
  the third-party notices for provenance records and their documentation limits.
- Follow the [user guide](../USER_GUIDE.md), [integrations guide](../INTEGRATIONS.md),
  [artwork guide](../ARTWORK.md) and [third-party notices](../../THIRD_PARTY_NOTICES.md).
