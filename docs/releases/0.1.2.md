# Retro Launcher 0.1.2 — Experimental preview

Artwork matching corrections for automatic lookup and **Find images**. Requires Android 13 or
newer; games and emulators are installed separately.

## Download and install

Download **retro-launcher-0.1.2-preview-debug.apk** and **SHA256SUMS** from this release's **Assets**.
Verify the APK checksum before installation.

**APK SHA-256:** `abc4d70a9de9fe78142f1377dd7aaccc79f6d07e15ea2ae84185e2038d4dd069`

**This is a debug-signed testing build, not a production-signed release.** Package:
`com.ariy.retrolauncher`; version `0.1.2`; version code `3`. It uses the same local debug key as
the previous previews and development-device installation.

Install over a same-key preview to retain launcher data. If Android reports a signing conflict,
stop rather than uninstalling or clearing storage: those actions erase library data and grants.
Other machines and future production builds may use a different key. Keep another Home launcher
installed while testing.

## Changes

- Web artwork fallback requires actual, relevant result titles. Untitled raw URLs are no longer
  falsely labelled with the search query; irrelevant and physical-product results are filtered.
- Automatic web-image selection respects ranked result order instead of choosing a lower-ranked
  image just because its shape fits the tile. Exact catalog editions retain aspect-ratio selection.
- Download fallback no longer overwrites the primary Find images suggestions/cache.
- Automatic lookup uses the current saved title; manual lookup uses the entered title for both
  catalogs and web queries. Switch queries no longer override edited titles with old ROM filenames.
- Meaningful subtitle colons and dots are preserved; only known file extensions are stripped.
- Fixed URL validation rejecting valid image links without query parameters.
- Existing saved covers are preserved. Use **Find images** to select a replacement for an incorrect
  cover; this update does not silently overwrite manually selected artwork.

## Validation and limitations

- 201 JVM tests passed, including offline fixtures for result/title association and title cleanup.
- Application and Android instrumentation-test APKs compiled successfully.
- APK signature and package/version verified; in-place RG477M upgrade and startup succeeded without
  clearing data. No AndroidRuntime crash entries appeared in the inspected recent log.
- Live provider accuracy, on-device visual results, instrumentation execution and gameplay are not
  claimed as verified. Provider markup can change; unverifiable fallback results may remain empty.
- No production signing key is configured; this APK is debuggable and intended for testing.
- Android lint remains blocked by the documented Compose/Kotlin metadata-reader incompatibility.
- No in-app backup/export exists. Uninstall, clearing storage and Reset launcher lose data.
- Emulator compatibility depends on separately installed versions, setup and storage permissions.
- Third-party artwork retains its original source terms. Redistribution review for external cabinet
  downloads and derivatives remains unresolved; this preview does not establish blanket permission
  or relabel third-party assets as MIT. Notices are attached and included in the repository/APK.
