# Retro Launcher 0.1.4 — Experimental preview

Authentic cartridge labels, improved console artwork and consistent games-only mixed views.
Requires Android 13 or newer. Emulators, ROMs and games are installed separately.

## Download and installation

Download **retro-launcher-0.1.4-preview-debug.apk** and **SHA256SUMS** from the release assets.
Verify the checksum before installing. Package `com.ariy.retrolauncher`, version `0.1.4`,
version code `5`. This is a **debug-signed testing build, not a production-signed release**.

APK SHA-256: `e576597e16399d3837dc7899a49686eb416330baf3f709effa15cd71e0419bfa`

Install over a same-key preview to preserve data. If Android reports a signing conflict, stop:
uninstalling or clearing storage deletes library data and grants. Keep another Home launcher installed.

## Changes

- **Handheld artwork:** external GB/GBC/GBA stickers matched by full-ROM CRC, attributed Slot
  shells, artwork-derived plastic colors, manual overrides and atomic loading without cover flashes.
- **N64 cartridges:** exact normalized-header matching supplies portrait cartridge labels. Seven
  reviewed USA signatures can use sharper original crops; other matches retain database thumbnails.
  Offline failures retain fallback artwork. No guessed regional substitutions.
- **Console cases:** complete GameCube/PS2 covers retain headings/ratings; regional source selection
  is improved. PlayStation jewel cases retain molded cover tabs and side clips.
- **Mixed view:** standalone app/emulator tiles are excluded from All in grid and gallery. Dedicated
  Android/Emulators galleries and actual emulator-launched games are retained.
- **ScummVM/imports:** recognized generic shortcut icons upgrade to real covers without overwriting
  manual images or launch targets. Includes shortcut recognition, PS3/ARMSX3 presets, conservative
  scan/deduplication improvements, compact dialogs and updated platform badges.
- **Maintenance:** artwork inputs are consolidated; tools track original pixels, provenance and
  quality. All 313 N64 scans were cropped locally (306 new plus seven earlier crops). The local pack
  is not committed/bundled; those 306 scans are not additional verified runtime identities or a
  claim of 306 distinct games.

## Validation and limitations

- 243 JVM tests passed; app and Android instrumentation-test APKs compile.
- Targeted device regression tests cover shared mixed-list filtering against the saved library,
  cartridge loading, console-cover placement and retained CD case details.
- Local N64 preparation verifies every crop pixel, dimensions and source hash; repeated runs produce
  identical indexes/hashes. Tiny originals, damage, fading and moire remain flagged, not restored.
- Same-key installation/device tests passed on the immediately preceding development build without
  clearing the library. The device disconnected before the final version-bumped APK could be installed;
  its signature and version metadata are verified, but a final 0.1.4 device upgrade is not claimed.
  Full UI stress tests,
  every emulator/game launch, regional artwork variant and gameplay are not certified.
- Android lint has a previously documented Compose/Kotlin metadata-reader compatibility limitation;
  no lint pass is implied. No production signing or in-app backup/export is provided.
- Third-party artwork retains original terms. Public accessibility and credits do not establish
  redistribution permission; external cabinet/photo/derivative rights review remains unresolved.
  Slot shell GPL-3.0-or-later notices/license and cartridge source notes accompany the APK.
  No downloaded game-sticker collection is bundled; third-party media is not relicensed as MIT.
