# Retro Launcher 0.1.1 — Experimental preview

An experimental update addressing emulator selection, platform navigation, ScummVM setup and
cramped settings. Android 13 or newer is required; emulators and games are installed separately.

## Download and install

Download **retro-launcher-0.1.1-preview-debug.apk** and **SHA256SUMS** from this release's **Assets**.
Verify the APK checksum against SHA256SUMS before installing. Android may ask you to allow
installation from your browser or file manager.

**APK SHA-256:** `a04705e158b48d9a29e2c2006396d20e9dff5efa8a638cb45c1ad7d3815cc90d`

**This is a debug-signed testing build, not a production-signed release.** It uses the same local
debug key as the 0.1.0 preview and the development-device installation. Package:
`com.ariy.retrolauncher`; version: `0.1.1`; version code: `2`.

Install over the existing same-key preview to retain launcher data. If Android reports a signing
conflict, stop rather than uninstalling or clearing storage: those actions erase the library and
permissions. Builds from another machine and future production builds may use a different key.
Keep another Home launcher installed while testing.

## Changes

- **Eden Optimized:** remains selectable alongside Eden even when both presets share the same
  installed package and launch contract. Choosing the preset does not install a different emulator.
- **Circular platform navigation:** a platform's temporary empty loading snapshot no longer causes
  it to be skipped immediately when cycling backward. Cycling wraps in both directions.
- **ScummVM first setup:** Android-published game shortcuts are imported automatically. If no
  usable shared shortcuts or registered targets are available during first setup, ScummVM's own
  registered-game picker opens without requiring a manually added first tile. Setup also offers
  exported configuration import for bulk addition and safe skip/cancellation. Choosing one game
  does not expose ScummVM's private full library.
- **Settings space:** Reset launcher now sits inside the scrolling General settings. The oversized
  fixed destructive warning is removed; the explicit confirmation and data-loss warning remain.
- Version code increased for upgrades from 0.1.0; existing library records and selections are retained.

## Validation

- 196 JVM tests across 44 suites passed.
- Application and Android instrumentation-test APKs compiled successfully.
- APK signature and package/version checked before upload.
- Upgrade installation and launcher startup checked on an RG477M without clearing data.
- No crash entries found in the inspected process-specific AndroidRuntime log.
- Device visual checks, instrumentation execution, gameplay and measured performance remain
  unverified: screenshots were black and keyguard was reported. These are not claimed as passed.

## Known limitations

- No production release signing key is configured. The APK is debuggable and intended for testing.
- ScummVM's private library is not directly enumerable; bulk import requires an exported existing
  configuration or Android-published shortcuts. Folder markers alone cannot register games.
- Emulator compatibility depends on installed versions, public launch contracts, core/BIOS setup
  and separate storage permissions. A successful scan is not a gameplay compatibility guarantee.
- Android lint remains blocked by the documented Compose/Kotlin metadata-reader incompatibility;
  no lint pass is asserted.
- No in-app library backup/export exists. Uninstall, clearing storage and Reset launcher lose data.
- Third-party artwork retains its source terms. The documented redistribution review for external
  cabinet downloads and derivatives remains unresolved; this preview does not establish blanket
  permission or relabel third-party assets as MIT. See the notices before reusing assets.
