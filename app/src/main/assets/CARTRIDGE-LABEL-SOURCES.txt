Bundled GB / GBC / GBA cartridge labels

Retro Launcher includes 347 user-supplied GB / GBC / GBA label images in
artwork/gb/, artwork/gbc/ and artwork/gba/. Runtime matching uses the full ROM CRC32 and system
from each platform's artwork/<platform>/index.json. The two revised GB images are
GB-0FD1AE54.png (Pocket Bomberman, Europe) and GB-85748525.png (Parodius,
Europe); the supplied README identifies them as AI-recreated regional labels.
The other 345 images were retained byte-for-byte from the downloaded cache.

Optional downloaded Nintendo 64 cartridge labels

Source: https://archive.org/details/Analogue3Dcartdatabase
File: https://archive.org/download/Analogue3Dcartdatabase/labels.db
Format reference: https://github.com/Chrisser73/analogue-3d-labels-db-editor
The format documentation was consulted; no upstream code is copied.

Reviewed higher-resolution original cartridge scans:
https://archive.org/details/N64_Cartridge_Art_Collection
Uploaded by Jason Scott (2016); source filenames, exact ROM-header signatures,
SHA-256 digests and manually reviewed sticker crop coordinates are recorded in
artwork/n64/scans.json. Seven reviewed USA labels use 305-343 by 350-381 original pixels.
Each scan is fetched separately and only the sticker rectangle is cached. Unknown
or unreviewed variants retain the exact lower-resolution label, not another region.
No AI reconstruction or invented lettering is used. These scans have no declared
media license either; original owners retain rights, with no redistribution grant.

The fallback pre-loaded Analogue 3D label database contains 74x86 pixel portrait images.
The approximately 22 MiB database is downloaded into cache on first N64 label lookup,
size/SHA-256 verified, then read locally using an exact normalized first-8-KiB ROM CRC.
No ROM bytes are uploaded. Ordinary box artwork is not overwritten.
This is not Slot artwork, is not affiliated with Analogue or Nintendo, and is not
bundled or relicensed under MIT. The archive does not declare a media license;
availability is not public-domain or redistribution permission. Original rights
remain with their respective owners. Review media rights before redistribution.

Optional downloaded Nintendo Entertainment System cartridge labels

Reviewed source: https://archive.org/details/TheLegendofZelda-NES-CartScans
The Legend of Zelda, NES-ZL-USA, original USA release only. This is a label crop
from an existing cartridge scan, not AI reconstruction or invented lettering.
Source JPEG is described by the uploader as scaled and possibly retouched.
Source SHA-256, dimensions and crop are recorded in artwork/nes/scans.json.
Only metadata ships; no game scan is bundled. Downloads are bounded, hash-verified,
region-decoded and cached. Matching uses complete-ROM SHA-1 (including iNES header)
from libretro-database, not filenames, fuzzy titles or guessed regional substitutes:
https://github.com/libretro/libretro-database
Database attribution: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/
No ROM bytes are uploaded. Manual labels take priority; ordinary covers are unchanged.
The scan metadata declares no media license. Download availability is not permission
to redistribute, public-domain status or an MIT license. Original rights remain
with their owners. No affiliation or endorsement by Nintendo or the source is implied.
Separate media-rights review is required before distribution or hosting of images.
